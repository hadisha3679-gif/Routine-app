# روتین — پروژه Flutter

این پروژه یک نسخه آغازین سبک از اپلیکیشن فارسی «روتین» است.

## امکانات فعلی
- رابط فارسی و راست‌چین
- نمایش تاریخ شمسی
- صفحه خانه با نوار پیشرفت روزانه
- ثبت، انجام و حذف کارها
- ثبت مشتری و ویرایش راه ارتباطی، زمان پیگیری و یادداشت
- ثبت و حذف برنامه‌های باشگاه
- ذخیره محلی اطلاعات با SharedPreferences
- طراحی روشن، پویا و مینیمال با رنگ سبز رشد و نارنجی تأکیدی

## نیازمندی‌ها
- Flutter SDK نصب‌شده
- Android SDK برای ساخت APK

## اجرای پروژه
در پوشه پروژه اجرا کنید:

```bash
flutter pub get
flutter run
```

## ساخت APK اندروید
```bash
flutter build apk --release
```

فایل خروجی معمولاً در این مسیر قرار می‌گیرد:

`build/app/outputs/flutter-apk/app-release.apk`

## نکته درباره نسخه فعلی
این نسخه، هسته اولیه رابط و ذخیره اطلاعات است. اعلان‌های زمان‌بندی‌شده، زمان‌بندی هوشمند پیشرفته، پشتیبان‌گیری و آزمون روی دستگاه واقعی هنوز باید در مراحل بعد اضافه و آزمایش شوند. برای استفاده از تاریخ شمسی، بسته `shamsi_date` در وابستگی‌ها آمده است.

## ساخت APK فقط با گوشی (بدون نصب Flutter)

برای ساخت APK از سرویس ابری Codemagic استفاده کنید:

1. فایل ZIP پروژه را در گوشی از حالت فشرده خارج کنید.
2. در GitHub یک مخزن جدید بسازید و فایل‌های داخل پوشه پروژه را در مخزن بارگذاری کنید (خود فایل ZIP را به‌تنهایی بارگذاری نکنید).
3. وارد https://codemagic.io شوید و با GitHub وارد شوید.
4. مخزن پروژه را به Codemagic اضافه کنید. فایل `codemagic.yaml` از قبل برای ساخت APK تنظیم شده است.
5. ساخت را شروع کنید؛ پس از موفقیت، در بخش Artifacts فایل APK را دانلود کنید.

این تنظیم برای ساخت APK آزمایشیِ قابل نصب (debug) است و نیازی به کلید امضای انتشار ندارد. برای انتشار رسمی در Google Play باید نسخه release و امضای اختصاصی تنظیم شود.
